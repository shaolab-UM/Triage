# Release scope

This is a minimal publication code/data release.

Included:

- core Triage and CL-Linker workflow code;
- configuration and prompt-related code required by the public workflow;
- 50 primary and 42 validation publication-facing final JSON records;
- primary masked DEG inputs and final round-1 Handling Editor payloads;
- selector-control source data and deterministic reproduction;
- CL-Linker evaluation data/scripts available from the retained project snapshot;
- CellMarkerDB sensitivity summary/source-data checks;
- release validation utilities.

Not included:

- manuscript figure-rendering scripts;
- table-formatting scripts;
- development/repair/debug histories;
- obsolete pipeline versions;
- full multi-round raw LLM/Chief-QC trace archives;
- deleted historical scripts that could not be recovered.

The release therefore documents and reproduces the retained core workflow and reported publication-facing result layer without claiming that every historical intermediate artifact is available.
