# Provenance

This repository is released as Triage v1.0.0.

The public result files preserve the reported cluster-level decisions,
evaluation fields and model-generated rationale. Triage v1.0.0 is the software
release identifier used throughout the public code and publication-facing
outputs.

Retained round-1 Handling Editor payloads are included as model-facing input
records. Development histories, repair logs and obsolete working copies are
outside the scope of this minimal release.
